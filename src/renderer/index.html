Позиция по скриншотам

Игра пишет координаты в имя файла скриншота. Читаются только имена новых файлов. Скриншот — игровой клавишей (Print Screen), не Steam.

Безопасность

Игра не трогается: память не читается, код не внедряется, трафик не перехватывается. Источники — текстовые логи игры, открытая база tarkov.dev и скриншоты квестов с вики (escapefromtarkov.fandom.com, CC BY-SA). Окно — обычное окно Windows; в игре нужен режим «Оконный без рамки».
